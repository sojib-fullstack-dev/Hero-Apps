# HERO.IO 🚀

HERO.IO is an app marketplace website where users can explore apps, view app details, and manage their installed apps.

## 🌐 Live Website

[Visit HERO.IO](https://hero-apps-web.vercel.app/)

## 📸 Features

- 🏠 Home page with hero section
- 📱 Browse available apps
- 🔍 Search and explore apps
- ⭐ App ratings and reviews
- 📥 Install apps
- 🗑️ Uninstall installed apps
- 📄 App details page
- 🔔 Success notification after uninstall
- 📱 Responsive design for mobile, tablet and desktop
- 🎨 Modern UI using Tailwind CSS and DaisyUI

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify
- Next.js Image
- React Context API
